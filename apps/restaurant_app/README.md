# DineEasy — Staff App (Flutter)

The staff-facing mobile/desktop client — POS, Kitchen Display, Tables, Billing, Reports, Staff,
and Settings — for one restaurant outlet on `services/api`. This was originally scaffolded by
`flutter create .` (hence `.metadata`, `.fvmrc`, `pubspec.lock`, and friends, which stay
version-controlled per Flutter's own convention); this file replaces the generated placeholder
that boilerplate leaves behind.

Full documentation — architecture, what's built vs. planned, RBAC, and how to run it — lives at
[`docs/flutter-app.md`](../../docs/flutter-app.md) in the repo root, alongside the rest of
`docs/`. Start there rather than here.
